Support Ticket Manager

API do obsługi zgłoszeń wsparcia z trwałym zapisem w SQL Server, logowaniem i kontrolą dostępu. Ukończony etap projektu edukacyjnego, uruchamiany lokalnie.

  • Własne zgłoszenia użytkownika i pełna kolejka wsparcia
  • Logowanie i role z ASP.NET Core Identity
  • Sortowanie aktywnej kolejki według priorytetu
  • ASP.NET Core Minimal API i odpowiedzi JSON
  • Odczyt szczegółów z kontrolą właściciela
  • Rozpoczęcie, zamknięcie i ponowne otwarcie zgłoszenia
  • Walidacja danych i ograniczenia w bazie
  • Rozdzielenie endpointów, serwisu i reguł
  • Automatyczny ID, autor i domyślny priorytet 2
  • Aktywna kolejka oraz archiwum
  • Trwały zapis SQL Server przez EF Core
  • 101 testów reguł, API, SQL i uprawnień

  • .NET
  • ASP.NET Core
  • EF Core
  • SQL Server
  • Identity
  • xUnit
